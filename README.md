# 🤖 AI Chat UI Clone

A modern AI chat interface inspired by ChatGPT, built using HTML, CSS, and JavaScript.

## 🚀 Features

- Clean AI-style chat interface
- User and AI chat bubbles
- Dynamic message rendering
- Auto-scroll to latest messages
- Responsive chat layout
- Fake AI response simulation

## 🛠️ Tech Stack

- CSS3
- JavaScript (Vanilla JS)
